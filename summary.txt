ShellMentor v4.5.0 — Project Summary
======================================
Professional Linux Command-Line Learning Platform
Author: Kunal Saraswat | License: MIT | September 2026

WHAT IT IS
----------
Terminal-based (TUI) learning platform for Linux command-line skills.
Built with Python 3.10+ and Textual framework. All data stored locally
in SQLite. No external services required. Submissions are graded
structurally against a reference solution — nothing a learner types is
ever executed (zero subprocess/os.system/eval/exec calls anywhere).

FEATURES
--------
1. Structured Lessons    — 14 tracks, 43 lessons with sections/exercises/quizzes
2. Command Lab           — Non-executing practice, 50+ autocomplete templates
3. Challenges            — 50 scored exercises with hints, opt-in Timed Mode,
                            and a "why this works" solution breakdown
4. Missions              — 10 multi-stage narrative learning objectives
5. Gamification          — 12-level ranking (Novice -> Grandmaster), 31 achievements
6. Notes                 — Search, edit, save, export
7. Analytics             — Progress stats, command usage, challenge breakdown
8. Theming               — 7 themes that actually re-skin the whole app via
                            Textual CSS variables, live switching
9. Backup & Restore      — One-file JSON export/import of all progress
10. Certificates          — Lesson completion certificates, saveable to file

ARCHITECTURE
------------
  UI Layer -> Engine Layer -> Data Layer
  (ui_core,      (learning,    (data_manager
   ui_screens,    challenge,    — SQLite)
   ui_activities) playground,
                   progress)

Engines communicate via callbacks. UI screens access engines via
self.app.<engine>. All persistence through DataManager.

WHAT WORKS WELL
---------------
- BaseScreen pattern eliminates UI duplication
- The no-execution policy is real, not decorative — structural grading only
- Achievement triggers handle AND/OR without eval()
- Command translator and regex visualizer add real pedagogical value
- Theme system re-skins the whole app, not just a handful of widgets
- Data layer has proper schema, WAL, foreign keys, and a JSON backup/restore path
- Challenge streak bonus incentivizes consecutive solving
- Certificate modal rewards high-score completion and can be saved to file
- Opt-in Timed Mode adds urgency to challenges without forcing it on every one
- Bookmark/resume system for lesson continuity
