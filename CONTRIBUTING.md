# Contributing to ShellMentor

1. Create a focused branch from `main`.
2. Keep curriculum changes in `data/` and application changes covered by tests.
3. Run `python3 -m compileall -q .` and `python3 -m pytest -q` before opening a pull request.
4. Do not add code that executes learner-supplied commands.
5. Describe user-visible changes and test evidence in the pull request.
