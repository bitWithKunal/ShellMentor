# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to the repository maintainer through GitHub's private vulnerability reporting
feature, including reproduction steps and the affected version.

## Execution policy

ShellMentor does not execute commands entered into lessons, challenges, the
Command Lab, missions, or Git guides. Those inputs are stored as learning
answers and assessed structurally only.
